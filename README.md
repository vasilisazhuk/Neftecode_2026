# Мультиагентная система (МАС) оптимизации производства дизельного топлива Евро-5

Проект разработан для технологической цепочки **«АВТ ➔ Гидроочистка 24-2000 ➔ Резервуарный блендинг»**.

## Ключевые принципы и физические обоснования
1. **Приоритет безопасности и ГОСТ 32511-2013:** Содержание серы строго меньше 10 мг/кг. Запрещено компенсировать выход за рамки качества экономической выгодой.
2. **Защита от утечки данных во времени (Lookahead Bias):** Учтен физический лаг публикации лаборатории: замер ЛИМС доступен МАС только через 4 часа после отбора пробы.
3. **Экономическая оптимизация:** Система оптимизирует компромисс между топливом печи гидроочистки и вводом цетаноповышающей присадки, которая стоит в 100 раз дороже ДТ.
4. **Регламентный отказ (Graceful Refusal):** При сбое поточных анализаторов и устаревании лаборатории система безопасно отказывается от слепого управления.
